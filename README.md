# CST8265 Group Assignment

## Application details
### YAPC: Yet Another Pastebin Clone

YAPC is a simple text sharing web app which allows users to create and share "pastes" with one another, or create hidden, encrypted pastes.

The project contains two applications:

`../yapc-vulnerable`: intentionally insecure implementation.

`../yapc-secured`: secured implementation.

`../documentation`: Additional documentation (attack matrix and Stride analysis)
